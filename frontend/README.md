# Frontend — AI EV Fleet Optimization

React + TypeScript + Vite dashboard for the EV fleet optimization platform.

## Scripts

```bash
npm install
npm run dev      # http://127.0.0.1:5173 (proxies /api → :8000)
npm run build
npm test
```

Requires the FastAPI backend running on port 8000 for live data. See the root [README](../README.md).
